# 聊天面板接入 SkillPie 技能市场搜索（原生详情 + 安装）

## 方案概述

在聊天 `/` 命令面板和 `$` 技能面板各新增「技能市场」分组：输入即异步搜索 SkillPie（debounce 250ms、限 6 条、置底展示）。选中后关闭面板，弹出 **ZCode 原生样式的技能详情弹窗**（数据来自 SkillPie 公开详情接口，`marked` 渲染文档），弹窗内可一键安装到 `~/.zcode/skills/<normalizedName>`。

已实测确认的外部契约（参考你 skillpie 工程的 CLI 源码 `~/.zcode/skills/skillpie/src/`）：
- 搜索 `GET /api/skills?query=&limit=` → `{ skills: [...] }`，公开免鉴权
- 详情 `GET /api/skills/by-normalized-name/<name>` → `{ skill }`，含 `usageInstructions`（markdown）、`skillMd`、`screenshots`、`version.versionNo/packageDownloadUrl/packageSize`、`isFree`，公开免鉴权
- 下载：详情里直接带 `version.packageDownloadUrl`（相对路径，拼 baseUrl）；免费技能 download-url 与 zip 下载均免鉴权（CLI update.ts 即无鉴权调用）

## 一、Spec 先行（AGENTS.md 要求）

更新 `specs/skill-market.md`：修改第 14 行「不做」清单（原生安装免费技能从"安装桥接不做"中放开；内嵌页深度集成仍不做），新增章节「聊天面板市场搜索与原生详情安装」：产品规则（两面板分组、触发条件、选中行为、安装语义、付费技能引导）、状态所有者图、事件顺序、验收场景（含 en-US、移动端 Web、断网错误态、同名已安装跳过）。

## 二、shared 类型与通道

- `packages/shared/src/channels.ts`：`ServiceChannels` 增加 `SkillMarket: "skill-market"`
- 新建 `packages/shared/src/skill-market.ts`：`SkillMarketSearchResult`（id/name/normalizedName/category/description/ownerDisplayName/downloadCount/likeCount/versionNo/isFree）、`SkillMarketSkillDetail`（含 usageInstructions/screenshots/version）、`SkillMarketInstallResult`（status: "installed" | "already-installed" / path / versionNo）；从 shared index 导出

## 三、服务层（packages/services/src/skill-market/）

新建 `skillMarket.ts`（`ISkillMarketService` 接口 + `createServiceDescriptor`，照 skillSync.ts 模式）与 `skillMarketService.ts` 实现：
- `searchSkills({ query, limit })`：fetch 搜索接口，宽松字段映射
- `getSkillDetail({ normalizedName })`：fetch 详情接口
- `installSkill({ normalizedName })`：详情 → `packageDownloadUrl`（回退 download-url 接口）→ 下载 zip → 复用 `skill-sync/skillSyncArchive.ts` 的 `extractSkillSyncArchive`（临时目录解压 + SKILL.md 校验 + 防路径穿越）→ 安装到 `~/.zcode/skills/<normalizedName>`，同名已存在返回 `already-installed`
- 注册：`accessor.ts` + `client/src/remoteServiceAccess.ts`（`ProxyChannel.toService`，Web 模式代理到 server 执行，规避浏览器 CORS）
- baseUrl：`process.env.ZCODE_SKILL_MARKET_URL` 回落 `DEFAULT_SKILL_MARKET_URL`（本地联调可指向自部署 skillpie）
- 测试 `packages/services/test/skillMarketService.test.ts`：mock fetch + 临时目录，覆盖请求参数、字段映射、安装成功/同名跳过/缺 SKILL.md 失败

## 四、UI 状态与搜索 hook

- 新建 `packages/ui/src/store/skillMarketStore.ts`：`detailSkill: { normalizedName } | null`（详情弹窗唯一所有者）、`openDetail/closeDetail`；弹窗宿主挂在 App 层，**无需跨 6 层穿 props**
- 新建 `packages/ui/src/hooks/useSkillMarketSearch.ts`：`{ query, enabled }` → trim 后非空才搜；250ms debounce + 请求序号/cancelled 丢弃过期响应（对齐 `CommandCenterDialog.tsx:578-620` 既有模板）；返回 `{ results, loading, error }`

## 五、`/` 面板接入

- `slashCommandHelpers.ts`：新增 `buildSkillMarketSuggestions(results)` → `PromptInputSuggestionItem`，id 前缀 `skill-market:`、`data.source: "skill-market"`、keywords 含分类/作者

## 六、`$` 面板接入

- `mentionPanelRouting.ts`：`MentionPanelGroupId` 增加 `"skill-market"`，`$` 的分组顺序变为 `["skills", "skill-market"]`
- `MentionPlugin.tsx`：调 `useSkillMarketSearch`（enabled = isOpen && isSkillTrigger && hasActiveQuery），`groupsById` 增加 skill-market 组；market 项 `MentionItem.category` 仍用 `"skills"`（不新增共享类型分支），以 id 前缀区分
- `insertMentionItem`：仿 whiteboard 分支先判 `skill-market:` 前缀 → 移除 token + `openDetail(...)`，不走 mention 插入
- `MentionPanel` 选项内容：market 项加「市场」徽标区分本地已装技能

## 七、原生详情弹窗（ZCode 样式）

新建 `packages/ui/src/skill-market/SkillMarketDetailDialog.tsx`，用既有 `components/ui/dialog.tsx`：
- 数据：挂载时 `getSkillDetail(normalizedName)`（loading/error 态）
- 头部：名称、分类徽标、作者、下载/点赞/版本/包大小；正文：`marked` 渲染 `usageInstructions`（复用既有 markdown 样式），`screenshots` 有则展示
- 底部：免费技能 →「安装」按钮（loading/成功/失败态；`already-installed` 提示已安装）；付费技能（`isFree: false`）→ 禁用 +「前往技能市场」打开既有内嵌市场视图（App 层 `handleOpenSkillMarket` 直接可达，弹窗宿主就在 App）
- 安装成功后无需额外刷新：`/`、`$` 面板每次打开都会重新拉 catalog（enabled 随面板开关注入，`useSkills` effect 重跑）

## 风险与说明

- 付费技能下载受限（`downloadLimited`）行为以实测为准，v1 统一走「前往技能市场」兜底
- agent 侧 `getSkillReferenceCatalog` 若对安装后新技能有快照延迟，实施时验证并在必要时补显式重扫触发（用真实安装验证，不预设兜底）
- skillpie 服务端不在本仓库，接口行为以 `~/.zcode/skills/skillpie` CLI 源码 + 线上实测为契约，已在方案中逐条实测确认
