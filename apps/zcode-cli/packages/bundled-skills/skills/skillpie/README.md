# SkillPie CLI

SkillPie CLI 是一个 AI 智能体技能库CLI工具，你可以在这里**发现、安装和发布**各种技能。

## 快速使用

### 发布技能
- 直接对智能体说：`发布 <技能目录> 到SkillPie`
- 发布技能包大小限制：10MB
- 首次发布技能需配置AppKey，智能体会引导完成

**技能目录要求**：
- 必须：`SKILL.md`（Agent技能说明书，LLM决策入口）
- 可选：`scripts/`（脚本目录，固定逻辑决策入口）
- 可选：`references/`（参考文档目录，以实现渐进式加载）
- 可选：`assets/`（资源目录）
- 可选：`previews/`（预览图目录，发布技能时可自动上传，最多5张图）
- 可选：`README.md`（用户简短使用说明书）

### 搜索技能
对智能体说：`搜索 <关键词> 相关的技能`

### 安装技能
对智能体说：`安装 <技能名称> 技能`
